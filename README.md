# Meeting-Decision-Extractor
# 📋 Meeting Decision Extractor Using NLP

## 📌 Project Description

**Meeting Decision Extractor** is a Natural Language Processing (NLP) application that analyzes meeting transcripts and automatically extracts important information.

The application identifies:

* 📌 Meeting decisions
* ✅ Action items
* ⏰ Deadlines
* 👥 Responsible people
* 📊 Meeting statistics

This helps users quickly understand the important outcomes of a meeting without reading the complete transcript.

---

## 🎯 Objective

The main objective of this project is to automatically analyze meeting conversations and identify the most important information.

Instead of manually reading a long meeting transcript, the application extracts important decisions and tasks automatically.

---

## 🔄 Working Process

```text
Meeting Transcript
        ↓
Text Preprocessing
        ↓
Sentence Detection
        ↓
Keyword Analysis
        ↓
Decision Detection
        ↓
Action Item Detection
        ↓
Deadline Detection
        ↓
Person Detection
        ↓
Generate Meeting Summary
```

---

## ✨ Features

* 📝 Meeting transcript input
* 📌 Decision extraction
* ✅ Action-item extraction
* ⏰ Deadline detection
* 👥 Responsible-person detection
